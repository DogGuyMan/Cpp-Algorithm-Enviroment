# 볼록 위치 Hamiltonian cycle 의 컨투어 면적

원 위에 배치된 $N$개 정점을 **중복 없이 한 번씩** 방문해 돌아오는 닫힌 cycle($N$개 간선)을 그린다.
간선끼리 교차할 수 있고, 이때 만들어지는 도형의 면적을 구한다.

이론 배경 전체 : [Doc/계산기하_평면분할과_다각형면적_보고서.md](../../Doc/계산기하_평면분할과_다각형면적_보고서.md) — 특히 **§3-B**와 **부록 F**

---

## 채택한 정의 : nonzero fill

> 별 모양의 **중심이 칠해져 있다** = 겹친 영역도 "안쪽"으로 친다 → **nonzero rule**
> 단, 면적은 겹친 횟수와 무관하게 **1번만** 센다.

`main.cpp`는 이 값을 표준출력에 한 줄로 출력한다.

## 네 가지 후보값 — 절대 헷갈리면 안 되는 지점

| 값 | 정의 | 별의 중심(winding 3)을 |
|---|---|---|
| **nonzero fill** ✅ | winding ≠ 0 인 영역 | **1번** 센다 |
| even-odd fill | winding 이 홀수인 영역 | 뚫린다(제외) |
| raw shoelace | winding 가중 면적 | **3번** 센다 |
| outer | 최외곽 윤곽 내부, 구멍까지 메움 | 1번 + 빈 주머니도 포함 |

**{10/3} 오각별 실측** (반지름 1000 정10각형, 방문순서 `1 4 7 10 3 6 9 2 5 8`):

```
nonzero fill  : 2245236.0   <-- 정답
even-odd fill : 1980221.6
raw shoelace  : 4755486.0   (2배 이상 차이!)
winding 분포  : w=-3 1개 (중심), w=-2 10개, w=-1 10개
```

> ⚠️ 무작위 cycle 20,000개 측정 결과 이 값들은 **75~100%의 경우 서로 다릅니다.**
> 가장 흔한 오답은 알고리즘 버그가 아니라 **넷 중 엉뚱한 것을 구현한 것**입니다.

## 구현 요점

| 단계 | 하는 일 | 주의 |
|---|---|---|
| 1 | 모든 선분 쌍의 교차점 계산 | $O(N^2)$ |
| 2 | 교차점에서 선분 분할 | 정렬 키는 방향 사영 |
| 3 | 정점 중복 제거 → 평면 그래프 | **정확 유리수 정규형 필수** |
| 4 | 정점별 각도 CCW 정렬 | `atan2` 금지, 반평면+외적 |
| 5 | `next` 따라 face 추출 | 유계 face는 CCW(양수) |
| 6 | face 대표점으로 winding 계산 | 왼쪽 법선으로 $\varepsilon$ 이동 |

**무게중심 두 곳** — 여기만 맞으면 나머지는 따라온다.

1. `MakeRatPoint` — 정규형 유리수. *어떤 점들이 같은 점인가*
2. `NextHalfEdge` — CCW 직전 간선. *어떤 사이클이 face인가*

## 자체 검증 (항상 켜둘 것)

- `sum(유계 face 면적) == |outer|` — 연결 그래프이므로 성립해야 함
- `even-odd ≤ nonzero ≤ outer` — 정의상 성립해야 함
- Euler: $V - E + F = 2$ (무한면 포함)

깨지면 십중팔구 ① `NextHalfEdge`의 CCW 방향이 반대 ② 유리수 정규화 누락.

## 함정 두 가지

**정다각형은 축퇴 지뢰밭이다.** 반지름 1000 정10각형에서 **주대각선 5개가 전부 원점을 정확히 통과**한다.
일반 위치라면 차수 4일 교차점이 여기선 차수 10이 된다. (본 구현은 견딤 — 20,000 표본 위반 0회)

**`__gcd` 금지.** macOS libc++에서 `std::__gcd`는 부호 있는 타입을 `static_assert`로 거부한다.
리눅스 채점 서버(libstdc++)에서는 통과해서 로컬과 동작이 갈린다. → `GcdLL` 직접 정의.

## 좌표 범위 한계

정수 좌표 $|x|,|y| \le C$ 기준:

- $C \le 1000$ : 그대로 안전 (`MakeDir` $\approx 3.8\times10^{17}$ < `ll` 한계)
- $C \le 10^4$ : **`MakeDir`가 `long long`을 넘긴다** → `Dir`를 `__int128`로 올릴 것
